# Rubik's Cube Timer

A concise 3×3 cube timer with random move-notation scrambles and a six-face scramble preview.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Controls

Hold the space bar or the left mouse button for 1.5 seconds. Release when the timer turns green to start, then press space or click once to stop.
